# PONDULO media and content sources

Project: Team 6, NISC 2026 — NeaPolis Innovation Summer Campus.

- `prototype.jpg`: project repository, `docs/assets/pondulo-prototype.jpg`.
- `hero_live.webp`, `internal_head.webp`, `internal_base.webp`, `campus_side.webp`,
  `pondulo_icon.png`, `demo_pondulo.mp4`: team project media presented at
  https://pondulo.vincenzonet.it/assets/media/ (Vincenzo D’Ambrosio).

Technical case-study content follows the README and architecture, hardware,
validation and review documents at https://github.com/EmanuelChirico/Pondulo,
reviewed on 22 November 2026. Team names and presentation inspiration come from
https://pondulo.vincenzonet.it/. Attribution and a link to the original interactive
3D presentation appear in the project story.

The case study describes the primary prototype separately from the standalone
ESP8266 price experiment. Configured rates are not latency measurements; native
software tests do not establish hardware accuracy or timing.
